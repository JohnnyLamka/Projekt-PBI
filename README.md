**Vývoj mezd, cen potravin a HDP v České republice**

Power BI projekt vytvořený v rámci Datové akademie ENGETO.

Cílem projektu je analyzovat vývoj průměrných mezd, cen potravin a HDP v České republice a zobrazit jejich vývoj v období 2006–2018.

**Obsah reportu**

Report je rozdělen do 5 stránek:

- Přehled
- Mzdy
- Ceny
- HDP
- Analýza

Report obsahuje interaktivní filtry podle roku, odvětví a kategorií potravin.

**Hlavní otázky**

Projekt se zaměřuje především na:

1. Vývoj mezd v jednotlivých odvětvích.
2. Vývoj cen vybraných potravin.
3. Porovnání kupní síly u mléka a chleba.
4. Porovnání meziročního růstu mezd a cen potravin.
5. Vývoj HDP a jeho vztah ke mzdám a cenám potravin.

**Použité nástroje**

- Power BI
- Power Query
- DAX
- SQL
- PostgreSQL
